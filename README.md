# Simon-Says-Game
The "Simon Says" game is a web-based implementation of the classic memory game using HTML, CSS, JavaScript.

![Image](https://github.com/user-attachments/assets/25687efb-17cb-4550-8a02-431932f2e1e3)

:video_game:Game Play Steps: Let's Play!
<hr>
1. Start the Game:
   :black_small_square: To start the game, Press any key on the keyboard.
2. Observe the Sequence:
   :black_small_square: As the game started one of the four colored boxes :red_square: :yellow_square: :green_square: :purple_square: will flash.
   :black_small_square: The game will display the sequence of colors,one at the time.watch carefully and try to remember the sequence.
3. Repeat the Sequence:
   :black_small_square: After the sequence is displayed,its your turn to repeat it.
   :black_small_square: Click on the button in same order as the sequence.
4. Level Up:
   :black_small_square: If you repeat the sequence correctly, you'll level up.
   :black_small_square: the game will display a new sequence as you level up.
5. Game Over:
   :black_small_square: If you make mistake by clicking incorrect box, the game will end.
   :black_small_square: and it will display your final level score.
   :black_small_square: To restart the game again, press any key on keyboard.

   Hope You Enjoyed The "GAME"
